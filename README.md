精选、可持续维护的 **SEO 工具清单**（中英工具都收，偏实战）。

> **定位**：帮运营 / 增长 / 内容 / 独立开发者快速选型，而不是堆链接或做外链农场。  
> **原则**：第三方精品为主；自有产品少量、披露、且必须已有真实流量。

## 为什么长期有价值

| 原则 | 做法 |
| --- | --- |
| 先官方后付费 | 每个工作流优先给可长期使用的官方/基础设施工具 |
| 少而精 | 同类只留代表性产品，不追求“千条目录” |
| 可验证 | 链接可访问；付费工具标明 Paid/Freemium |
| 可维护 | 死链可扫；变更写 [CHANGELOG](./CHANGELOG.md) |
| 反 spam | 自有站单独披露、数量封顶，见 [OWNED-SITES](./OWNED-SITES.md) |

## 5 分钟上手（先装这些）

做 SEO 不必先订阅贵套餐。多数站点先把下面跑通：

1. [Google Search Console](https://search.google.com/search-console) — 查询表现、收录、体验问题  
2. [Google Analytics 4](https://analytics.google.com/) — 行为与转化  
3. [PageSpeed Insights](https://pagespeed.web.dev/) — Core Web Vitals  
4. [Rich Results Test](https://search.google.com/test/rich-results) — 结构化数据  
5. 国内站再加：[百度搜索资源平台](https://ziyuan.baidu.com/)
